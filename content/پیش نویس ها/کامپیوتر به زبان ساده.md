- اینترنت: یعنی مجموعه ای از شبکه های متصل به هم که کامپیوترهای داخل آن میتوانند همدیگر را ببینند و با هم حرف بزنند. زبان دنیای اینترنت. پروتکل TCP/IP است. منظور از کامپیوتر هر دستگاهی است که می‌تواند به این زبان حرف بزند و بفهمد. موبایل، تبلت، لپ تاپ، و حتی دستگاه های هوشمند جدید مثل یخچال های هوشمند یا سرخ کن هوشمند که به اینترنت وصل می‌شوند.

- وب: قبل از اینکه دنیای وب به وجود بیاد، هیچ سایتی نبود. هیچ مرورگری هم نبود. آدم هایی که در اینترنت بودند فقط می‌توانستند برای هم فایل ارسال کنند یا با پروتکل های قدیمی چت کنند یا ایمیل بزنند. هر چیزی که داخل یک مرورگر باز می‌شود بخشی از دنیای وب است. همه سایت ها، نسخه های وب تلگرام، اینستاگرام و ... زبان دنیای وب html, css و javascript است. برنامه نویس ها سایت ها را با این زبان ها می‌نویسند.

- مرورگر: مثلا google chrome یا firefox برنامه ای است که زبان html, css و javascript را می‌فهمد. پس می‌تواند کدهایی که برنامه نویس برای ساخت صفحه یک سایت نوشته را پردازش کند. متن ها و تصاویر و شکل و شمایل سایت را بسازد(طبق کدی که برنامه نویس برای آن سایت نوشته) و به کاربر نشان دهد.
- سایت: در واقع هیچی نیست به جز چند فایل با فرمت html,css , js و ... که با ترتیب درستی کنار هم قرار گرفته اند و مرورگر می‌فهمد که آنها را چطور باید پردازش کند تا یک تصویر و متن درست از سایت بسازد و به کاربر نمایش دهد.
- سرور: یک کامپیوتر همیشه روشن است که به اینترنت وصل است. کسی که صاحب سرور است از کامپیوتر خودش به سرور متصل می‌شود(با پروتکل SSH) و دستوراتی که میخواهد را روی سرور اجرا می‌کند. یعنی مثلا برنامه ای روی سرور نصب می‌کند یا تنظیماتش را تغییر می‌دهد. همه سایت ها روی یک سرور قرار دارند. یعنی همان فایل های html , js ... مدیرسایت وارد سرور میشود و با دستکاری آن فایل ها سایت را به روز می‌کند و تغییرات دلخواه خودش را اعمال می‌کند.

نکته: اینترنت فقط وب نیست! پروتکل های دیگر نظیر FTP (برای انتقال فایل) یا SSH (برای مدیریت سرورها) و ... همه بخشی از دنیای اینترنت هستند ولی توسط کاربران عادی کمتر استفاده می‌شوند. مدیران سایت ها یا برنامه نویس ها با این بخش از اینترنت کار می کنند.


یک مثال علمی: فرض کنید شما وارد گوگل کروم (یا فایرفاکس یا هر مرورگر دیگر) می‌شوید و آدرس adliran.ir را می‌نویسید و دکمه Enter را می‌زنید. مرورگر شما یک درخواست می‌فرستد به سروری که سایت adliran.ir روی آن قرار دارد. سرور که روی آن یک برنامه به اسم web server نظیر Nginx یا Apachi نصب شده، درخواست مرورگر شما را دریافت می‌کند و فایل های مربوط به صفحه اول سایت (متن ها، عکس ها و کدهای html , js, css , ...) را برای کامپیوتر شما میفرستد تا مرورگر آن ها را دریافت کند و مورد پردازش قرار دهد و صفحه را آنطور که شما می‌بینید، بسازد.


**حالا سوال اصلی! api چیست؟**
- واسط(رابط) برنامه نویسی کاربردی یا به اختصار API یعنی اینکه شما به جای وارد شدن به سایت، مستقیم با سرور صحبت کنید! مثلا API گوگل به شما اجازه میدهد به جای اینکه مجبور باشید وارد سایت گوگل شوید و یک عبارت را جستجو کنید، به طور مستقیم در کدهایی که خودتان می‌نویسید(مثلا یک اسکریپت پایتون) API گوگل را هم وارد کنید تا کدهایی که توسط شما نوشته شده اند، مستقیم به سرور های گوگل متصل شوند. در این صورت شما می‌توانید مثلا ۱۰۰ کلمه را بدون اینکه وارد سایت گوگل شوید و دکمه «جستجو» را فشار دهید، با همان چند خط کد پایتون که خودتان نوشته اید، جستجو را انجام دهید. در واقع api چیزی است که این امکان را فراهم می‌کند تا یک برنامه با برنامه دیگر صحبت کند! به جای اینکه آدم ها با برنامه صحبت کنند. در همین مثالی که زدیم، به جای اینکه یک آدم با سایت گوگل تعامل کند، یک برنامه(خودش) با گوگل تعامل می‌کند. و چون برنامه ها محدودیت آدم ها را ندارند، مثلا می‌توانند در ۲-۳ ثانیه ۱۰۰ کلمه را در گوگل جستجو کند و تمام نتیجه را در یک فایل ذخیره کنند!

نکته مهم: همه سرور/سایت ها api ندارند. باید برنامه نویس آن سایت برای آن api هم بنویسد. هرسایتی که api می‌سازد، یک صفحه ای به نام «مستندات api» قرار میدهد تا برنامه نویس ها با مطالعه آن بدانند که به چه زبانی و چه مدلی باید با سرور حرف بزنند تا جواب بدهد.

وب اسکرپینگ Web scraping یعنی چی؟
همه سایت ها api ندارند. یا دارند ولی عمومی نیست. api رو به همه نمی‌دهند. در این حالت یک نوع از برنامه نویسی است که در اون کدهایی که نوشته میشه، با سایت تعامل می‌کند (نه مستقیما با سرور). یعنی مثل یک آدم روی دکمه ها کلیک می‌کند و عبارت ها را تایپ می‌کند. ولی آدم نیست! پس این امکان را دارد که با سرعت خیلی بیشتر اطلاعات را از روی سایت (نه از روی سرور به طور مستقیم) استخراج کند. یا اطلاعات را وارد سایت کند.
سایت ها معمولا دوست ندارند که این مدل برنامه ها(ربات های scraper) روی صفحات حرکت کنند. مثلا پیام معروف I am not a robot گوگل که به کاربر نمایش داده می‌شود و باید تصاویر خاصی را انتخاب کنید تا ثابت کنید واقعا یک آدم هستید و ربات نیستید. منظور از robot دقیقا همین مدل برنامه هایی است که به جای آدم ها با گوگل حرف می‌زنند. گوگل دوست ندارد فریب بخورد. اگر قرار باشد برنامه ای با گوگل حرف بزند باید به طور رسمی api درخواست کند و از طریق همان با سرور های گوگل تعامل کند، نه اینکه یک برنامه به جای آدم ها کار کند.

فرق اصلی بین اسکریپت و برنامه بیشتر به نحوه‌ی اجرا، پیچیدگی و هدف برمی‌گرده تا یه مرز فنی دقیق. اما به‌طور کلی
-  **برنامه‌ها** معمولاً پروژه‌های بزرگ و پیچیده‌ای هستند که پکیج کاملی از قابلیت‌ها، رابط کاربری گرافیکی (GUI) و مدیریت عمیق منابع سیستم را شامل می‌شوند (مثل سیستم‌عامل‌ها، مرورگرها یا ابزارهای مدیریت پایگاه داده).
- **اسکریپت‌ها** معمولاً برای اتوماسیون (خودکارسازی کارهای تکراری)، پردازش و استخراج سریع داده‌ها، یا به عنوان یک «چسب» برای متصل کردن و انتقال دیتا بین چند نرم‌افزار مختلف و بزرگ استفاده می‌شوند.
**یک تشبیه ساده:** یک **برنامه** مثل یک کارخانه بزرگ و خودکفاست که از صفر تا صدِ یک محصول را تولید می‌کند. اما یک **اسکریپت** مثل یک ربات کوچک یا یک دستورالعملِ سریع است که وارد یک محیط (مثلاً همان کارخانه) می‌شود تا فقط یک کار خاص — مثل بسته‌بندی یا جابه‌جایی جعبه‌ها — را خودکار کند.
